# Store submission checklist

- [ ] Permanent Android application ID and iOS bundle ID approved.
- [ ] Production Firebase/App Check/APNs configuration verified externally.
- [ ] Android/iOS signing and symbol upload confirmed without committing keys.
- [ ] Version/build identifiers aligned with candidate evidence.
- [ ] Icons, screenshots, listing text, support URL, and privacy URL supplied.
- [ ] Camera, photos, location, and notification disclosures reviewed.
- [ ] Google Play Data safety and App Store privacy declarations reviewed.
- [ ] Account deletion process and review instructions supplied.
