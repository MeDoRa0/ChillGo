# Incident record template

```md
# Incident <id>
- Severity and affected versions:
- Aggregate impact:
- Detection time and owner:
- Containment decision (pause, disable signal, revoke access, or removal):
- Corrective candidate or rollback:
- Root cause and prevention follow-up:
```

Never include user, crew, outing, invitation, vote, chat, location, credential,
token, or raw exception content in an incident record.
