# ChillGo privacy policy draft

ChillGo processes account, crew, outing, agreement, chat, notification, avatar,
and optional live-meetup location data to provide crew coordination. Location is
shared only when a participant explicitly enables it for an accepted meetup and
is removed when the outing completes. Chats expire according to product rules.
Firebase services support authentication, storage, notifications, App Check,
aggregate analytics, and crash diagnostics. Operational telemetry contains only
release version, Android/iOS client type, controlled category, and allowlisted
journey completion; it excludes messages, names, IDs, precise location, votes,
invitations, tokens, credentials, raw network data, and raw exceptions.

Before publishing, replace this draft with the release owner's approved public
URL and document account-deletion contact/process in store metadata.
